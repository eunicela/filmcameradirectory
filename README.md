# Film Camera Darkroom

A lightweight prototype for a film camera directory and darkroom companion.

The current prototype is a dependency-free static web app that lets you:

- Browse and filter a starter catalog of film cameras.
- Load a camera into a roll desk with notes and recommended film stock.
- Compare development recipes by film stock and developer.
- Run a session timer with darkroom process steps.

## Getting started

Open `index.html` directly in a browser, or serve the folder locally:

```bash
npm run serve
```

Then visit `http://localhost:4173`.

## Development checks

Run the JavaScript syntax check:

```bash
npm run check
```

No package install is required for the current static prototype.
